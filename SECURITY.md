# Segurança / Security

## Português

Não publique credenciais, chaves administrativas, tokens ou dados de usuários em uma issue. Relate uma vulnerabilidade de forma privada ao mantenedor pelo perfil do GitHub.

O Marcão Boost altera configurações do Windows. Revise cada ajuste, mantenha um ponto de restauração e use somente builds publicados neste repositório.

## English

Do not publish credentials, administrative keys, tokens, or user data in an issue. Report vulnerabilities privately to the maintainer through their GitHub profile.

Marcão Boost changes Windows settings. Review each tweak, keep a restore point, and use only builds published by this repository.
